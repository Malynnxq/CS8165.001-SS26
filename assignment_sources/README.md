# Assignment Sources

This folder contains the extracted contents of the original exercise ZIP packages so the code, PDFs, shaders, CMake files, and framework files can be browsed directly on GitHub.

- `exercise-01/` - extracted from `assignment_zips/Exercise1.zip`
- `exercise-02/` - extracted from `assignment_zips/Exercise2.zip`
- `exercise-03/` - extracted from `assignment_zips/Exercise3.zip`
- `exercise-04/` - extracted from `assignment_zips/Exercise4.zip`

The generated assignment overview pages remain in `assignments/`, and the plain text extraction remains in `course_text_parts/04_assignments/`.
