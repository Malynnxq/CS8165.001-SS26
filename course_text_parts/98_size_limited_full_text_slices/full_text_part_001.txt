General 
The lecture covers the fundamental concepts of interactive 3D computer graphics, as used in video games and 3D modeling. Central to this is the rendering pipeline, which serves as the conceptual foundation for modern image synthesis systems. The algorithms discussed are initially dealt with theoretically in the lectures before a selection is practically implemented in the exercises. The practical implementation is carried out in C/C++ in combination with the graphics standard OpenGL. An introduction to C/C++ will be provided at the beginning of the exercises. The following topics are covered in the lecture: 
Graphics programming in OpenGL 
Geometric transformations and projections 
Lighting calculations 
Clipping algorithms 
Rasterization and texturing 
Geometric modeling

OpenGL Setup 
At the beginning of the semester, students should prepare their computers, such that they can develop and execute OpenGL applications in C/C++. To do so, please follow the instructions below: 
Install Visual Studio Code and the two extensions C/C++ and CMake Tools ( code.visualstudio.com/docs/languages/cpp ). 
Install CMake ( cmake.org ). 
Download OpenGL starter project ( opengl-rotatingcube.zip ) which contains a VS Code-ready project structure. 
Unzip OpenGL starter project to a folder which you open in VS Code . 
Run the following commands in the VS Code Command Palette (open with Ctrl+Shift+P on Windows/Linux or Cmd+Shift+P on macOS):
CMake: Configure 
CMake: Build 
CMake: Debug 
If successful an OpenGL Window with a rotating cube should appear. In case you have problems with this setup, please post in the forum or ask during the labs.
