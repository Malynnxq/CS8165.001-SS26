Comparison with Cohen-Sutherland
 Algorithm of Cohen-Sutherland
(cid:127) Sometimes performs useless clip operations,
as clipping and testing are done in a fixed order
(cid:127) Efficient when outcode tests can be performed inexpensively (e.g., by bitwise
operations) and the majority of line segments are trivially accepted or rejected
(cid:127) Especially efficient for large clip rectangles, when almost all lines are inside, and
small clip rectangles when almost all lines are outside
(cid:127) Generalizable to 3D
 Algorithm of Cyrus-Beck / Liang-Barsky
(cid:127) Beneficial if many lines really need to be clipped, because calculating the
coordinates of the clip intersections is delayed as long as possible and the
necessary tests are performed using the parameter values
(cid:127) Generalizable to convex clip-polygons and 3D

public VertexList shClipper(VertexList inputVertices, Edge clipE) {
VertexList outputVertices; // output list of vertices
int N = inputVertices.size(); // number of vertices to be processed
Vertex s = inputVertices.get(N-1); // get last vertex
for (int j = 0; j < N; j++) {
Vertex p = inputVertices.get( j );
if (inside(p, clipE)) {
if (inside(s, clipE)) { // case 1
outputVertices.add( p );
} else { // case 4
outputVertices.add( intersect(s, p, clipE) );
outputVertices.add( p );
}
} else if (inside(s, clipE)) { // case 2
outputVertices.add( intersect(s, p, clipE) );
}
s = p;
}
return outputVertices;
}

Intersection Computation
 For rectangular clip regions
Vertex intersect(Vertex p, Vertex s, Edge e) {
Vertex i;
if (e.v0.y == e.v1.y) { // horizontal edge
i.y = e.v0.y;
i.x = p.x + (e.v0.y - p.y) * (s.x - p.x) / (s.y - p.y);
} else { // vertical edge
i.x = e.v0.x;
i.y = p.y + (e.v0.x - p.x) * (s.y - p.y) / (s.x - p.x);
}
return i;
}
