Code Reading and Debugging Drills
=================================
These are closed-format OpenGL/software questions.

1. A model renders but nearer triangles do not hide farther triangles. What is most likely missing?
   A. Depth testing or depth buffer setup
   B. Only mipmaps
   C. Only ambient lighting
   D. Only CMake comments
   Answer: A

2. A shader expects a matrix uniform but objects ignore camera movement. What should you inspect?
   A. Whether the view/projection uniform is updated and used
   B. Whether README exists
   C. Only texture file size
   D. Only back-face color
   Answer: A

3. A textured object appears stretched. What is a likely issue?
   A. Wrong or missing texture coordinates
   B. Too many Git commits
   C. Ambient term too high only
   D. No shadow bias only
   Answer: A

4. Everything renders black after adding lighting. What should be checked first?
   A. Normals, light direction, material values, shader outputs
   B. Only branch name
   C. Only PDF page count
   D. Only zip filename
   Answer: A

5. Shadow acne appears. Which parameter is commonly adjusted?
   A. Shadow bias
   B. Git remote
   C. Course title
   D. HTML viewport
   Answer: A
