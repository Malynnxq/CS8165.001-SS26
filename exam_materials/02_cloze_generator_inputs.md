# 02 - Cloze Generator Inputs

Copy one block at a time into a cloze generator. These texts are coherent by design: they include cause, data, operation, output, and common trap.

## Lecture 01 - Introduction

Computer graphics generates images from descriptions; interactive graphics adds a strict time budget and a feedback loop with the user. The concept chain is scene or image description -> representation choice -> sampling or rendering process -> visible image -> interaction or analysis. raster image means A grid of stored pixel samples; it is already an image, not a 3D scene. pixel means A discrete image sample containing color or channel values. color depth means The number of bits used to represent color values, controlling precision and memory size. 3D model means A structured description of geometry and attributes that can generate many possible images. primitive means A basic geometric object such as a point, line, or triangle used by the rendering pipeline. interactive graphics means Rendering where images must update quickly enough to respond to input or animation. A compact rule for this lecture is: image memory = width x height x bits per pixel, then divide by 8 for bytes. The assignment connection is 00 Introduction to C++. The main trap is: Do not confuse an image representation with the geometric cause of the image.

Suggested blanks: raster image, pixel, color depth, 3D model, primitive, interactive graphics, image memory = width x height x bits per pixel, then divide by 8 for bytes

## Lecture 02 - Rendering Pipeline

Rendering is a sequence of representation changes: models become vertices, primitives, fragments, tested fragments, and finally framebuffer updates. The concept chain is application data -> geometry stage -> primitive assembly -> rasterization -> fragment operations -> framebuffer. application stage means CPU-side preparation of models, scene data, interaction, animation, and rendering state. geometry stage means Pipeline stage that transforms vertices and prepares primitives. rasterization means Conversion of projected primitives into fragment candidates on a sample grid. fragment means A candidate pixel contribution produced by rasterization before final tests and blending. framebuffer means Memory target that stores color, depth, stencil, or related per-pixel results. double buffering means Using front and back buffers so drawing can happen off-screen before display swap. A compact rule for this lecture is: vertices -> primitives -> fragments -> tests -> pixels. The assignment connection is 01 Rendering Pipeline. The main trap is: Do not collapse the whole pipeline into 'the GPU draws it'; name the intermediate representations.

Suggested blanks: application stage, geometry stage, rasterization, fragment, framebuffer, double buffering, vertices -> primitives -> fragments -> tests -> pixels

## Lecture 03 - Geometric Transformations

Transformations change how points, vectors, normals, and coordinate frames are expressed across model, world, view, and clip-related spaces. The concept chain is object/model coordinates -> model matrix -> world coordinates -> view matrix -> camera/view coordinates. homogeneous coordinates means Coordinates with an additional component that make translation and projection expressible by matrices. translation means A transformation that moves points by an offset; direction vectors are not shifted the same way. rotation means A transformation that changes orientation while preserving distances. scaling means A transformation that changes size and can distort normals if handled incorrectly. matrix composition means Combining transformations by multiplication, where order matters. normal transformation means Transforming surface normals consistently, often requiring inverse-transpose logic under non-uniform scaling. A compact rule for this lecture is: p_world = M_model * p_model; p_view = V * p_world. The assignment connection is 03 Geometric Transformations. The main trap is: Do not multiply matrices without naming source space, target space, and order.

Suggested blanks: homogeneous coordinates, translation, rotation, scaling, matrix composition, normal transformation, p_world = M_model * p_model; p_view = V * p_world

## Lecture 04 - Geometric Projection

Projection maps camera-space geometry into clip coordinates and then normalized device coordinates before viewport mapping. The concept chain is view-space position -> projection matrix -> clip coordinates -> perspective divide -> NDC -> viewport coordinates. view volume means The 3D region visible to the camera before mapping to the screen. orthographic projection means Projection without perspective foreshortening; parallel lines stay parallel. perspective projection means Projection where farther objects appear smaller after division by the homogeneous component. clip coordinates means Coordinates produced before clipping and perspective divide. perspective divide means Division by w that produces normalized device coordinates. viewport transformation means Mapping normalized device coordinates to window or screen coordinates. A compact rule for this lecture is: p_clip = P * p_view; p_ndc = p_clip.xyz / p_clip.w. The assignment connection is 04 Projections and Clipping. The main trap is: Do not confuse projection with viewport mapping; the perspective divide sits between them.

Suggested blanks: view volume, orthographic projection, perspective projection, clip coordinates, perspective divide, viewport transformation, p_clip = P * p_view; p_ndc = p_clip.xyz / p_clip.w

## Lecture 05 - Clipping

Clipping classifies geometry against boundaries and keeps, rejects, or cuts primitives before rasterization. The concept chain is primitive -> boundary tests -> inside/outside classification -> intersections -> clipped primitive. clipping means Removing or cutting geometry outside a valid window, plane, or volume. Cohen-Sutherland means Line clipping method using region/outcodes to reject, accept, or clip line segments. Sutherland-Hodgman means Polygon clipping method that processes polygon vertices against clipping boundaries. Cyrus-Beck means Parametric line clipping method using entering and leaving parameter intervals. outcode means A compact code describing where a point lies relative to clipping boundaries. intersection point means New boundary point created when a primitive crosses a clipping edge or plane. A compact rule for this lecture is: line point p(t) = p0 + t * (p1 - p0), then restrict t to the visible interval. The assignment connection is 04 Projections and Clipping. The main trap is: Do not describe clipping as only deletion; crossing primitives can create new vertices.

Suggested blanks: clipping, Cohen-Sutherland, Sutherland-Hodgman, Cyrus-Beck, outcode, intersection point, line point p(t) = p0 + t * (p1 - p0), then restrict t to the visible interval

## Lecture 06 - Rasterization

Rasterization converts continuous projected geometry into discrete fragment candidates and interpolated per-fragment attributes. The concept chain is projected primitive -> sample coverage -> fragment generation -> attribute interpolation -> fragment tests. scan conversion means Determining which discrete samples are covered by an ideal geometric primitive. triangle coverage means Testing which pixel/sample positions lie inside a triangle. barycentric coordinates means Weights relative to triangle vertices used for inside tests and interpolation. interpolation means Computing per-fragment values from vertex attributes. aliasing means Artifacts caused when continuous signals are sampled too coarsely. fragment candidate means A potential contribution to the framebuffer, not yet a guaranteed visible pixel. A compact rule for this lecture is: attribute = alpha * a0 + beta * a1 + gamma * a2, with alpha + beta + gamma = 1. The assignment connection is 05 Rasterization. The main trap is: Do not call every generated fragment a final pixel.

Suggested blanks: scan conversion, triangle coverage, barycentric coordinates, interpolation, aliasing, fragment candidate, attribute = alpha * a0 + beta * a1 + gamma * a2, with alpha + beta + gamma = 1

## Lecture 07 - Visibility Determination

Visibility algorithms decide which candidate surface is actually seen from the current viewpoint. The concept chain is many projected or intersected candidates -> comparison rule -> visible surface or fragment -> final image contribution. depth buffer means Per-pixel storage of depth values used to keep the nearest visible fragment. z-buffer algorithm means Image-space visibility method comparing fragment depths at each pixel. Painter's algorithm means Object-order visibility method based on drawing farther objects before nearer objects. BSP tree means Space-partitioning structure that can support visibility ordering. Warnock algorithm means Image-space subdivision method for resolving visible surfaces in regions. ray casting means Finding visible surfaces by tracing rays from image samples into the scene. A compact rule for this lecture is: visible fragment = candidate with passing depth/visibility test at the sample. The assignment connection is Rasterization and integrated rendering tasks. The main trap is: Do not confuse generating a fragment with proving that it is visible.

Suggested blanks: depth buffer, z-buffer algorithm, Painter's algorithm, BSP tree, Warnock algorithm, ray casting, visible fragment = candidate with passing depth/visibility test at the sample

## Lecture 08 - Local Illumination

Local illumination computes color from surface orientation, light direction, view direction, and material response. The concept chain is surface point + normal + light + view + material -> lighting equation -> shaded color. surface normal means Vector describing surface orientation and controlling diffuse/specular response. ambient term means Approximate base illumination independent of direct light direction. diffuse reflection means View-independent light response based on the angle between normal and light direction. specular reflection means View-dependent highlight term based on reflection or half-vector alignment. Phong model means Local illumination model combining ambient, diffuse, and specular components. material coefficient means Parameter controlling how strongly a surface responds to lighting terms. A compact rule for this lecture is: color = ambient + diffuse + specular. The assignment connection is Rendering contest and shader-related tasks. The main trap is: Do not mix up normal, light direction, and view direction; each changes a different lighting term.

Suggested blanks: surface normal, ambient term, diffuse reflection, specular reflection, Phong model, material coefficient, color = ambient + diffuse + specular

## Lecture 09 - Texturing

Texturing uses coordinates and sampler state to fetch stored data and interpret it in a shader. The concept chain is fragment coordinates -> texture coordinates -> sampler/filter/wrap state -> texel fetch -> shader meaning. texture means Sampled data array used for color, normals, material data, depth, or other shader inputs. texel means A stored sample in texture memory. UV coordinates means Coordinates that map surface locations to texture space. filtering means Rule for reconstructing values between texels, such as nearest or linear filtering. mipmap means Precomputed lower-resolution texture levels used to reduce aliasing and improve sampling. environment mapping means Using texture lookup to approximate surrounding reflections or distant lighting. A compact rule for this lecture is: sampled value = texture(sampler, uv), then shader interprets the value. The assignment connection is Rendering contest and texture/shader tasks. The main trap is: Do not reduce texturing to pasting an image onto geometry.

Suggested blanks: texture, texel, UV coordinates, filtering, mipmap, environment mapping, sampled value = texture(sampler, uv), then shader interprets the value

## Lecture 10 - Shadows

Shadows are visibility tests from the light source, not only dark shapes seen by the camera. The concept chain is light -> possible blocker -> receiver point -> light-space visibility test -> lit or shadowed result. shadow means Reduced direct illumination where an object blocks light from reaching a receiver. occluder means Object that blocks light. receiver means Surface where the shadow appears. shadow map means Depth image rendered from the light's point of view for later visibility comparison. shadow volume means Volume of space hidden from a light by an occluder. projective shadow means Shadow construction based on projecting geometry onto a receiver. A compact rule for this lecture is: point is shadowed if something is closer to the light along the same light ray. The assignment connection is Rendering contest and integrated lighting tasks. The main trap is: Do not explain a shadow only from the camera view; the key test is light-space visibility.

Suggested blanks: shadow, occluder, receiver, shadow map, shadow volume, projective shadow, point is shadowed if something is closer to the light along the same light ray
