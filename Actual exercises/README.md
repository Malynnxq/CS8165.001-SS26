# Actual exercises

This directory is reserved for companions based on the **real course exercise sheets/files**, kept separate from the reconstructed study companions in `exercise_readers_v2/`.

Each actual-exercise companion should include:

- the real exercise task text or a faithful structured transcription of it;
- explicit links to the lecture-reader sections that contain the prerequisite knowledge;
- a step-by-step solution;
- explanations of why each step is valid;
- implementation notes where the sheet contains C++ / OpenGL / GLSL code;
- common mistakes and exam-relevant takeaways.

## Current source status

The repository currently still exposes only the old Moodle assignment page for Exercise 1 under `assignments/01-rendering-pipeline/`; the real Exercise 1 attachment/source file is not visible on either `main` or `textbook-readers-all-lectures` at the time this directory was created.

No “actual Exercise 1” companion is generated here until the genuine Exercise 1 task file is available, so reconstructed questions are not mislabeled as official course tasks.
