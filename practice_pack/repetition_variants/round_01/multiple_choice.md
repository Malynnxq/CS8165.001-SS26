Multiple Choice Variants round_01
=================================

1. Which statement is true?
   A. A fragment is guaranteed visible
   B. A fragment may still be discarded
   C. A texel is a vertex
   D. A framebuffer is a shader
   Answer: B

2. Which pair is easiest to confuse but different?
   A. Clipping and culling
   B. CPU and keyboard
   C. PDF and shader
   D. Git and texture
   Answer: A

3. What does a projection matrix help produce?
   A. Clip/projected coordinates
   B. Texture filenames
   C. CMake cache only
   D. Forum posts
   Answer: A

4. What does mipmapping address?
   A. Texture sampling quality
   B. Git history
   C. Lecture dates
   D. Back-face orientation only
   Answer: A
