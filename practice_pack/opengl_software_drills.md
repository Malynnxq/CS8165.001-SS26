OpenGL and Software Drills
==========================
Answer these without code first, then inspect the OpenGL starter project.

1. Shader role
   Explain what data should be computed in a vertex shader versus a fragment shader.

2. Buffer setup
   List the conceptual steps for sending vertex data to the GPU and drawing primitives.

3. Uniforms
   Explain what a uniform variable is and why transformation matrices are commonly uniforms.

4. Attributes
   Explain what vertex attributes are and name typical examples.

5. Depth test debugging
   Name symptoms when depth testing is disabled or configured incorrectly.

6. Texture debugging
   Name possible causes when a textured object renders black, white, or stretched.

7. Projection bug
   Describe what might be wrong if objects disappear when moving the camera.

8. Shadow bug
   Describe likely causes of shadow acne or detached shadows.
